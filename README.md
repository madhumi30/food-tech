# StudySpace — Food Science Notes Library

A responsive static notes website inspired by the folder-based Grade 8 notes website.

## Features
- Seven separate subject folders, each with its own home page and chapter folder.
- Food Processing and Preservation Technology populated with 50 two-mark questions and answers, plus a 52-question long-answer library.
- Search, dark mode, animated cards, expandable answers, revision tracking, responsive navigation and back-to-top control.
- Other subjects are structured and ready for notes to be added as you upload them.

## Run locally
Open `index.html` in a browser. For local testing with paths, run a static server from this folder.

## Deploy
Upload the contents of this folder to GitHub and import the repository into Vercel, or deploy as a static site.
